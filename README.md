# an-portfolio

This project is deployed as a **Vite SPA** (static site) with **TanStack Router**.

## Deploy (Vercel)

- Build command: `npm run build`
- Output directory: `dist`
- SPA routing: `vercel.json` adds a rewrite to `/index.html` so deep links don’t 404.

## Local

- Dev: `npm run dev`
- Preview the production build: `npm run build && npm run preview`
